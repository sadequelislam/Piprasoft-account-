# একাউন্টস ও লেজার ম্যানেজমেন্ট ওয়েবসাইট (Firebase Integrated)

এই প্রজেক্টটি একটি সম্পূর্ণ রেসপন্সিভ একাউন্টস ম্যানেজমেন্ট ওয়েব অ্যাপ্লিকেশন, যা ফায়ারবেস (Firebase Hosting, Authentication, Firestore Database) দিয়ে লাইভ করার জন্য তৈরি করা হয়েছে।

## 🌟 ফিচারসমূহ:

১. **এডমিন লগইন পেজ**: ওয়েবসাইট URL দিয়ে কেউ ঢুকলে প্রথমে লগইন পেজ আসবে। সঠিক ইমেইল ও পাসওয়ার্ড দিলে হোম পেজে নিয়ে যাবে।
২. **লেফট সাইডবার নেভিগেশন**:
   - **১. ড্যাশবোর্ড (হোম)**: মোট জমা, মোট খরচ এবং বর্তমান ক্যাশ ব্যালেন্স রিয়েল-টাইমে হিসাব করে দেখায়।
   - **২. ফি প্রদান (জমা)**: গ্রাহক/সদস্যের ফি বা টাকা জমা এন্ট্রি করার ফর্ম।
   - **৩. খরচ (ব্যয়)**: বিভিন্ন খরচের খাত ও ভাউচারসহ ব্যয় এন্ট্রি করার ফর্ম।
   - **৪. সকল লেনদেন**: সকল এডমিনদের দ্বারা যুক্ত করা আয় ও ব্যয়ের সংকলিত রিয়েল-টাইম লেজার বিবরণী (ফিল্টারিং ও CSV ডাউনলোডের সুবিধাসহ)।
   - **৫. সেটিং**: ফায়ারবেস প্রজেক্ট কনফিগারেশন সেটআপ, এডমিন প্রোফাইল নাম, নাইট মোড অন/অফ এবং লোকাল ডাটা ব্যাকআপ রিসেট অপশন।

## 🚀 ফায়ারবেসে (Firebase) লাইভ ফ্রি URL তৈরি ও ডেপ্লয় করার ধাপসমূহ:

### ধাপ ১: ফায়ারবেস প্রজেক্ট তৈরি
১. [console.firebase.google.com](https://console.firebase.google.com/)-এ যান।
২. **Add project** এ ক্লিক করে একটি নতুন প্রজেক্ট তৈরি করুন (যেমন: `my-ledger-app`)।
৩. প্রজেক্ট তৈরির পর **Authentication** সেকশনে যান এবং **Sign-in method** থেকে **Email/Password** অপশনটি **Enable** করে দিন।
৪. **Firestore Database** সেকশনে গিয়ে **Create database** দিন এবং **Start in test mode** বেছে নিন।

### ধাপ ২: ওয়েব অ্যাপ যুক্ত করা ও API Key নেওয়া
১. Project Overview এর পাশে **Web (</>)** আইকনে ক্লিক করে একটি ওয়েব অ্যাপ তৈরি করুন।
২. আপনার প্রজেক্টের **Firebase Configuration Code** (`apiKey`, `authDomain`, `projectId` ইত্যাদি) পাবেন।
৩. ওয়েবসাইটটি চালু করে **৫. সেটিং (Settings)** ট্যাবে গিয়ে ওই কোডগুলো বসিয়ে সেভ করুন। অথবা `firebase-config.js` ফাইলে সরাসরি বসিয়ে দিতে পারেন।

### ধাপ ৩: বিনামূল্যে লাইভ ওয়েবসাইট URL তৈরি (Firebase Hosting Deploy)
আপনার কম্পিউটারে VS Code বা টার্মিনাল ওপেন করুন এবং প্রজেক্ট ফোল্ডারে গিয়ে নিচের কমান্ডগুলো চালান:

```bash
# ১. Firebase CLI ইনস্টল করুন (যদি আগে না করা থাকে)
npm install -g firebase-tools

# ২. আপনার গুগল একাউন্টে লগইন করুন
firebase login

# ৩. প্রজেক্ট ইনিশিয়ালাইজ করুন
firebase init hosting
# - 'Use an existing project' সিলেক্ট করে আপনার তৈরি করা প্রজেক্টটি সিলেক্ট করুন।
# - Public directory হিসেবে ' . ' (ডট) দিন।
# - Configure as a single-page app? -> Yes (y)
# - Set up automatic builds? -> No (n)

# ৪. প্রজেক্ট ফায়ারবেসে ফ্রিতে লাইভ ডেপ্লয় করুন
firebase deploy
```

ডেপ্লয় শেষে আপনি একটি ফ্রি **`.web.app`** বা **`.firebaseapp.com`** লিংক (যেমন: `https://your-project.web.app`) পেয়ে যাবেন, যা দিয়ে যেকোনো ডিভাইস বা গুগল ব্রাউজার থেকে লগইন করে ব্যবহার করা যাবে!
